# rustscan

- **Category**: Information Gathering / Reconnaissance
- **Risk Level**: 🟠 Medium

---

## Description

Fast port scanner + nmap. Focus areas: port, scan, fast.

## Installation

```bash
# linux: cargo install rustscan
# darwin: brew install rustscan
# win32: cargo install rustscan
```

## Usage

```bash
rustscan -a <a>
```

## Parameter Reference

| Parameter | Description |
|------|------|
| `-a` | Target (required) |
| `--range` | Port range |

## Tags

port, scan, fast
