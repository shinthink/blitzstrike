# zeek

- **Category**: Blue Team / Detection
- **Risk Level**: 🟠 Medium

---

## Description

Network security monitor. Focus areas: network, monitor, nsm. Alternatives: suricata.

## Installation

```bash
# linux: apt install -y zeek
# darwin: brew install zeek
# win32: manual
```

## Usage

```bash
zeek -r <r>
```

## Parameter Reference

| Parameter | Description |
|------|------|
| `-r` | PCAP (required) |
| `-C` | Ignore checksum |

## Tags

network, monitor, nsm
