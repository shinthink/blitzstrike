# certipy

- **Category**: Active Directory
- **Risk Level**: 🔴 High

## Description

AD CS abuse. Focus areas: adcs, certificate, ad.

## Installation

```bash
# linux: pip install --break-system-packages certipy-ad
# darwin: pip install --break-system-packages certipy-ad

```

## Usage

```bash
certipy -find <find>
```

| Parameter | Description |
|------|------|
| `find` | Mode (required) |
| `-u` | Username |
| `-dc-ip` | DC IP |
