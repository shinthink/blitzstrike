# gdb

- **Category**: Reverse Engineering
- **Risk Level**: 🟠 Medium

---

## Description

GNU debugger. Focus areas: debugger, binary. Alternatives: pwndbg, gef.

## Installation

```bash
# linux: apt install -y gdb
# darwin: brew install gdb
# win32: choco install gdb
```

## Usage

```bash
gdb - <>
```

## Parameter Reference

| Parameter | Description |
|------|------|
| `-q` | Quiet |

## Tags

debugger, binary

## Alternatives
